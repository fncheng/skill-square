UFW 防火墙使用指南

Ubuntu 服务器常用防火墙配置、启用与故障处理说明。

原文与批注分别保存

安装与启用

Ubuntu 通常已经预装 UFW。如果系统中没有该命令，可以先执行以下安装操作。

sudo apt update sudo apt install ufw

在远程服务器上启用 UFW 前，必须先放行 SSH 端口，否则当前连接可能被中断。

sudo ufw allow OpenSSH

设置默认策略

建议默认拒绝所有入站连接，同时允许服务器主动发起的出站连接。

sudo ufw default deny incoming sudo ufw default allow outgoing

启用防火墙

规则确认无误后，执行 sudo ufw enable 启用防火墙。正常情况下会提示防火墙已启用并将在系统启动时自动加载。

sudo ufw enable
启用后建议保留当前 SSH 会话，再新开一个终端验证远程连接，确认无误后再关闭原会话。

查看状态与规则

使用以下命令查看当前状态、默认策略以及已经生效的规则编号。

sudo ufw status numbered

如果输出中显示 Status: inactive，说明规则尚未正式启用；如果服务状态异常，还需要同时检查 systemd 服务和内核模块。
