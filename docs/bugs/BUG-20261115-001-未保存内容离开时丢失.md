# 未保存内容离开编辑页或关闭 SKILL 弹窗时丢失

来源：会话 `01a1dfea-7493-7ba2-9569-9f5587ba3f06` 的高优先级审查问题。状态 `fixed` 表示代码修复已提交，不代表已完成浏览器或真实接口验收。

## 问题现象和影响

编辑页返回、浏览器导航或关闭 SKILL 手动编辑弹窗时，尚未保存的内容可能丢失。该影响来自代码路径推断，原审查未运行复现。

## 预期行为与复现步骤

1. 在资源编辑页修改正文或元数据，尝试页内返回、浏览器返回、刷新或关闭页面。
2. 修改 SKILL 手动编辑弹窗后，尝试关闭、取消或按 Escape。
3. 未保存时应允许继续编辑或放弃修改；没有修改或成功保存后不应提示。全屏切换不应误报。

## 原因与实际修改

原编辑页没有导航或 `beforeunload` 拦截，SKILL 手动编辑弹窗的关闭入口直接关闭。`c492d6d` 新增 `use-unsaved-changes.ts`，以表单快照判断变化并接入路由及浏览器提示；路由入口改用 `createBrowserRouter`，保存和加载完成后更新基线。SKILL 手动弹窗的关闭入口也进行确认。

涉及 `apps/web/src/main.tsx`、`apps/web/src/hooks/use-unsaved-changes.ts`、六类资源编辑页和 `apps/web/src/views/SkillCenter.tsx`。

- 未进行浏览器交互、延迟请求模拟或真实接口验证；未运行构建或编译。以下场景仍需验收。
