# 导入 HTML 直接替换原型源码

来源：会话 `01a1dfea-7493-7ba2-9569-9f5587ba3f06` 的高优先级审查问题。状态 `fixed` 表示代码修复已提交，不代表所有浏览器与真实接口场景均已验收。

## 问题现象和影响

导入 HTML 会替换当前原型源码，没有事先确认。误选文件可能覆盖正在编辑的内容；影响基于代码路径推断，未运行复现。

## 预期行为与复现步骤

1. 输入非空 HTML 源码后导入不同文件。
2. 选择取消时保留当前源码；选择确认后替换源码。导入相同内容或当前源码为空时无需替换确认。

## 原因与实际修改

原文件读取完成后直接将文件内容写入 `form.html`。使用项目确认弹窗提示替换；读取文件或等待确认期间源码发生变化时重新确认。同时在导入期间禁用保存。

涉及 `apps/web/src/views/UiPrototypeEditor.tsx`。

## 验证结果

- 已进行代码检查，修改文件的语法解析及 `git diff --check` 通过。
- 本地 Chrome：已有非空源码时导入不同的本地 HTML，取消后原源码保留；再次导入并确认后编辑器显示新文件内容。未保存或创建业务资源。
- 未验证空源码、相同内容和等待确认时源码变化；未运行构建或编译。
