# Markdown 全屏编辑目录实施方案

## 1. 结论与范围

推荐在共享 `MarkdownEditorPanel` 中接入已认可原型的可收起目录。目录读取同一轮 `useMarkdown` 解析结果，并使用源码块标识定位对应预览节点和 Monaco 行。宽屏目录并排展示，较窄视口使用抽屉；继续保留同一 Monaco 实例、表单状态和保存链路。

本轮只修改前端共享编辑器、目录组件、必要类型和相关 CSS；不修改 API、数据库、资源编辑页面的提交逻辑、详情页目录规则或普通编辑布局。不引入依赖，不移植原型的模拟编辑器、Markdown 解析器、示例文档、保存反馈和 URL 状态开关。

方案依据为当前源代码与 `prototype/markdown-fullscreen-toc.html`。旧全屏方案仅提供历史背景，其“初版不做滚动同步”等描述已不代表当前实现。

## 2. 已核对的实现事实

- `apps/web/src/components/markdown/MarkdownEditorPanel.tsx` 是学习笔记、解决方案、杂谈、模型回答和 Prompt 编辑器的共享面板。全屏通过固定覆盖层切换布局，不更换路由、不触发浏览器 Fullscreen API。
- 编辑使用 `PromptMonacoEditor`，现有 React 子树保持同一 Monaco 实例。分栏比例为 35% 至 70%，961px 起左右并排；960px 及以下使用编辑/预览 Tabs。
- `MarkdownPreview` 对 `deferredValue` 调用 `useMarkdown(source, { includeSourceBlocks: true })`，通过 `MarkdownContent` 渲染，保留代码高亮、Mermaid 和引用交互。
- `useMarkdown` 已返回 `headings` 和 `sourceBlocks`。标题数据包含 `level/text/id`；源码块包含 `blockId/kind/startLine/endLine`，通过 `data-md-block-id` 写入顶层 DOM。行号来自过滤引用定义之前的原始 Markdown，而非过滤后的数组索引。
- `NoteDetail.tsx` 中 `meta-item-toc` 使用 `headings` 生成标题链接；详情页没有全屏编辑器中的源码行定位需求。
- 现有同步滚动与鼠标源码行高亮由 rAF、Monaco 事件、块几何缓存和 ResizeObserver 实现。当前缓存只在同步启用时构建，目录必须拥有独立于同步开关的定位数据与当前位置更新能力。
- 元数据面板位于右侧，复用原表单。已有 `Esc` 处理会关闭元数据或退出全屏，并主动避开 Dialog 与引用浮层。目录抽屉接入时需要调整关闭优先级和焦点隔离。
- 标题 slug 可能重复。目录不能依靠全局 `getElementById` 或 slug 唯一性定位，否则同名章节会跳错。此任务不重写已有详情页锚点生成规则。
- 当前仅原型文件未跟踪。没有发现前端 lint 脚本；本轮开始时未发现 5173 或 3000 端口的开发服务。

## 3. 实现路径比较

用户已认可目录交互，以下只比较实现路径，不重新选择 UI 方案。

| 路径 | 核心思路 | 复杂度与成本 | 性能 | 维护与扩展 | 主要风险与适用场景 |
| --- | --- | --- | --- | --- | --- |
| A. 复用预览解析快照，推荐 | 在现有预览提交时同时发布标题与源码块；按块标识定位 | 中等，集中于共享编辑器 | 无重复解析；滚动更新合并为 rAF | 保持统一解析语义，可共享给各资源编辑页 | 需要隔离 deferred 源码版本和隐藏栏定位；适合当前项目 |
| B. 目录单独解析源码 | 单独正则或第二次调用 Markdown 解析获得标题和行号 | 初始较低，长期校准成本高 | 增加长文解析开销 | 代码块、引用定义和渲染版本容易与预览偏离 | 适合简单静态文本，不适合本项目复杂 Markdown 链 |

A 的优点是目录、DOM 和源码块来自同一份解析结果，重复标题也能按块定位；缺点是需要认真处理快照一致性与布局变化。B 容易快速接入，但会增加第二套解析或重复解析，修改标题期间容易出现目录与预览不一致，因此不采用。

## 4. 数据与组件边界

### 4.1 同一解析快照

扩展 `MarkdownPreview` 的提交回调，将 `headings` 与 `sourceBlocks` 一并交给父面板。只使用同轮解析中的顶层标题块，按文档顺序与标题数据对应，生成目录条目。条目包含标题层级、文本、原有锚点、原始行号及唯一块标识；新增编辑器目录专用类型放在 `apps/web/src/types/markdown-editor.ts`。

推荐保留 `useMarkdown` 和 `MarkdownHeading` 现有公开契约。确有必要修改解析器时，必须先说明依据并限制在编辑器映射元数据，不重写 Markdown 规则。现有源码块足以支持本次需求，预期无需修改解析器。

每份条目必须绑定它所对应的 Markdown 源码快照。仅在 `value`、`deferredValue`、已提交预览源码相同且 Monaco model 与该源码一致时执行跳转；输入尚未同步时保留既有目录但禁用过时条目，显示简洁“更新中”反馈，不让旧行号命中新源码。异步回调、rAF 和待定位操作均需要版本或源码校验，旧任务不能覆盖新快照。

### 4.2 目录呈现

将目录展示拆成 `MarkdownEditorToc.tsx`，负责标题层级、数量、当前章节、关闭按钮、空目录与更新状态。协调 Monaco、布局、元数据和键盘行为的逻辑保留在共享面板；可按职责新增局部 Hook 或纯工具，但不得扩大为全局状态重构。

目录使用本地 UI 控件和 `lucide-react`；复杂布局使用 `main.css`，沿用现有 design token。不增加搜索、固定开关、层级折叠、API、快捷键或持久化设置。原型里的模拟错误、加载 URL 状态不移植；只呈现真实解析更新状态与空目录，不新增无实际错误来源的重试业务。

## 5. 布局与交互

### 5.1 展示规则

- 全屏工具栏新增“目录”按钮，位置与原型一致。提供 `aria-label`、tooltip、`aria-expanded` 和 `aria-controls`。
- 1280px 及以上：目录宽 248px，与剩余工作区并排；无模态遮罩，编辑和预览持续可操作。
- 961px 至 1279px：目录为左侧抽屉，宽 280px；底层保留双栏，选择章节后收起。
- 960px 及以下：目录为宽 296px 的左侧抽屉，并限制最大宽度为视口减 48px；编辑/预览 Tabs 保持当前选择，点击目录不强制切换视图。
- 首次进入全屏时宽屏默认展开目录，窄屏默认收起。用户在本次全屏会话中的开关选择由局部状态维护，切换断点不主动推翻选择。
- 关闭目录后，其占位和焦点入口退出工作区。目录自身独立滚动，长标题换行，H1–H6 均可识别且层级可扫描。
- 目录开关只改变布局。`PromptMonacoEditor` 始终处在稳定位置，不能通过改 key、条件重建或重新挂载实现目录切换。剩余双栏的分隔比例继续限制在 35%–70%。

### 5.2 点击目录

1. 验证目录、预览和 Monaco 的源码版本相同。
2. 使用 `blockId` 在当前预览容器内查找目标；禁止依靠文档全局 slug 定位，同名标题必须分别可达。
3. 将 Monaco 光标定位到原始标题行，并将该行滚动至可读位置；仅执行定位，不更改正文、撤销栈或草稿。
4. 将预览容器滚动到对应标题块。显式目录跳转不受“同步滚动”开关限制。
5. 写入当前位置，并取消或标记已排队的自动同步任务，避免自动同步立即覆盖用户选择。
6. 抽屉模式下收起目录并回到目录入口焦点；宽屏保留目录。

当一栏因为窄屏 Tab 被隐藏、尺寸为零时，记录绑定源码快照的待定位条目；在该栏恢复可见、完成布局后应用，应用前重新校验版本。用户点击另一个标题或随后手动滚动时，应当取消被替代的旧待定位请求，不反复强制滚动到旧位置。

### 5.3 当前章节

使用 Monaco 光标/当前可见源码行和当前预览顶部标题块更新目录当前章节；监听真实交互的一侧，程序写入另一侧的滚动不应反向覆盖状态。目录定位数据独立于同步滚动开关，关闭同步后仍能更新当前章节和跳转。

滚动事件合并到 rAF；优先缓存标题节点与原始行号，避免每次滚轮事件重新解析 Markdown 或全量读取 DOM。分栏宽度、目录占位、Tab 可见性、预览版本以及 Mermaid 高度变化后按需重建几何。当前位置更新时使用 `aria-current="location"`；无标题时显示空状态，清除旧当前位置。

### 5.4 与元数据互斥

打开元数据时记录目录开关并暂时收起目录；关闭元数据后恢复此前状态。元数据仍是原来的表单节点，不复制字段或保存函数。通过目录入口切换回目录时，不出现短暂重叠或意外恢复旧抽屉焦点。

模态抽屉隔离底层编辑区域焦点，提供 Tab/Shift+Tab 焦点循环、关闭按钮、遮罩和 `Esc`；关闭后还原 `inert`、aria 状态和触发按钮焦点。宽屏目录为非模态导航，不限制编辑器焦点。

`Esc` 优先交给现有引用浮层和子 Dialog；否则关闭已打开的目录或元数据，二者都未打开时才退出全屏。新增目录的 `role="dialog"` 不应被旧有“跳过 Dialog”判断吞掉。退出全屏恢复被覆盖应用区域的原有状态，清理本次目录定位任务和事件订阅。

## 6. 修改责任范围

terra high worker 负责以下文件及完成上述交互所需的局部目录 Hook/工具文件。

| 文件 | 责任 |
| --- | --- |
| `apps/web/src/components/markdown/MarkdownEditorPanel.tsx` | 解析快照回调、目录状态、章节定位、当前位置、模态协调与稳定布局 |
| `apps/web/src/components/markdown/MarkdownEditorToc.tsx` | 新增目录呈现组件 |
| `apps/web/src/types/markdown-editor.ts` | 新增目录条目及必要编辑器专用类型 |
| `apps/web/src/assets/main.css` | 目录侧栏/抽屉、选中状态和工具栏窄屏适配 |

父 agent 负责本方案文件、worker 交接、实施审查及最终报告。worker 不修改方案、原型、项目知识文件、依赖、后端或 `.git`。需要扩大范围时先反馈具体原因，再决定必要的调整。

## 7. 验证与验收

### 7.1 当前可执行的检查

- 阅读最终 diff，确认只修改授权文件、无新增 `any`、必要类型和简短职责注释齐全。
- 检查 TS/TSX 语法、CSS 解析、`git diff --check` 和新增文件空白问题。
- 检查 `element-plus`、`@element-plus/icons-vue`、`<el-` 遗留引用。
- 查询现有 lint 配置和脚本；若没有，明确报告，不擅自添加依赖或配置，也不修复已有无关错误。
- 有现成且用户已启动的前端页面时，检查真实页面；不得启动 `pnpm dev:web`，不得为验证运行构建、编译或打包命令。静态语法检查不表述为构建、完整类型检查或运行验收。

### 7.2 真实页面验收清单

1. 1440px、1280px、1024px、960px、390px 和 320px：目录开关、双栏或 Tabs、工具栏标题与按钮不重叠、不横向溢出。
2. 点击前部、中部和末尾标题：定位正确源码行与对应预览块；同名标题、H1–H6、长标题均可分别定位。
3. 标题修改、标题删除、正文前插入引用定义、连续快速输入、空文档与无标题文档：目录和定位快照一致，代码块中的 `#` 不进入目录。
4. 关闭同步仍可目录跳转与更新当前位置；快速滚动、点击目录以及双栏改宽不产生循环滚动或跳回旧标题。
5. 窄屏在编辑和预览 Tab 下分别点击目录，当前 Tab 保持，恢复隐藏栏时才应用有效待定位任务；手动滚动不被旧定位覆盖。
6. 目录、元数据互斥，关闭元数据恢复目录；Tab 焦点循环、遮罩、关闭按钮、`Esc` 和引用浮层关闭优先级正确。
7. 切换目录、元数据、全屏和断点时，正文、表单、Monaco 实例、撤销历史及保存请求沿用原链路。
8. Mermaid 异步渲染改变正文高度后，当前章节与后续跳转仍正确；现有引用、代码高亮与源码鼠标行高亮不回归。

## 8. 风险与缓解

- **过时映射**：将目录、待定位请求和 rAF 绑定源码快照；尚未同步时禁用旧条目。
- **同步反馈循环**：复用并扩展现有程序滚动目标标记；目录显式跳转前清理自动同步队列。
- **隐藏栏零尺寸**：在可见布局恢复后应用待定位请求，禁止基于零尺寸计算偏移。
- **重复标题**：使用编辑器 `data-md-block-id`，保留原解析 slug 契约。
- **焦点清理遗漏**：效果函数恢复原始 inert/aria 状态，注销 Monaco、DOM、ResizeObserver 和 rAF 订阅。
- **验证环境缺失**：当前没有发现运行中的前端服务。若实施后仍不可用，如实列出运行验证缺口，不把原型检查当作生产组件验证。

可选后续优化仅在实际长文使用发现性能问题后考虑目录虚拟化；本轮不引入。

## 9. 本轮实施与验证结果

已由指定 terra high worker 完成四个授权前端文件的改动，父 agent 审查并修正同步回跳、隐藏栏分侧定位、模态焦点循环、DOM ref 类型、全屏列间距和隐藏源码栏恢复后的 Monaco 布局刷新。

- TS/TSX AST 语法检查、CSS/PostCSS 解析、变更空白检查通过；新增代码没有 `any` 或 Element Plus 引用。项目未配置现有前端 lint 脚本，未添加检查依赖。
- 使用 Node 24 原生 TypeScript 运行真实 `parseMarkdown`，验证 LF/CRLF、引用定义过滤后的原始行号、重复标题、H6、代码块标题排除、空正文和无标题正文，通过。
- 从实际源文件提取目录构建、源码章节定位和预览二分查询纯函数，验证原始行号、独立块标识、边界和空目录，通过；未生成编译产物。
- 从实际源文件提取导航函数，用模拟 Monaco 和 DOM 几何对象检查分侧待定位、隐藏栏不写滚动、布局刷新、完成后不重复定位，以及过时源码/model 阻止跳转，通过。此项属于逻辑模拟检查，不代表真实编辑器验收。
- 没有运行前端开发服务，因此未完成生产组件浏览器视觉、真实焦点、真实 Monaco 撤销/滚动、Mermaid 重排或实际保存验证。未执行构建、编译、`tsc` 或完整类型检查。第 7.2 节的真实页面清单仍需在可用页面上验收。
