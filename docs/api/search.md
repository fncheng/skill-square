# 全局搜索接口

全局搜索用于在顶部导航中按标题查找所有一级内容资源。当前覆盖 Prompt、解决方案、学习笔记和 UI 原型，不搜索正文、摘要、分类或标签。

## GET /api/search

### Query 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `query` | `string` | 是 | - | 标题搜索关键词，最大长度 `120` |
| `limit` | `number` | 否 | `12` | 最多返回的结果数量，范围 `1-50` |

搜索不区分大小写。结果优先按标题完全匹配、标题前缀匹配和标题包含匹配排序，相同匹配等级按更新时间倒序排列。

### 响应

```json
{
  "items": [
    {
      "id": "786da6f1-8c64-4150-af33-382ab105a519",
      "title": "Bug 排查助手",
      "resourceType": "PROMPT",
      "updatedAt": "2026-07-13T01:53:15.349Z"
    }
  ]
}
```

`resourceType` 可选值：

- `PROMPT`
- `SOLUTION`
- `NOTE`
- `UI_PROTOTYPE`
