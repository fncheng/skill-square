# 全局搜索接口

全局搜索用于在顶部导航中按标题、摘要或标签查找所有一级内容资源。当前覆盖 Prompt、解决方案、学习笔记、杂谈和 UI 原型；有效管理员会话额外得到模型回答结果。首期不搜索正文、分类、Prompt 历史版本、模型名称或来源产品。

## GET /api/search

### Query 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `query` | `string` | 是 | - | 标题、摘要或标签搜索关键词，最大长度 `120` |
| `limit` | `number` | 否 | `12` | 最多返回的结果数量，范围 `1-50` |

搜索不区分大小写，且使用包含匹配；`%`、`_` 和 `\` 均按普通字符处理。Prompt 搜索 `name`、`description` 与关联标签，其他资源搜索 `title`、`summary` 与字符串标签。

结果按以下相关性排序：标题完全匹配、标题前缀匹配、标题包含匹配、标签完全匹配、标签前缀匹配、标签包含匹配、摘要包含匹配；相同匹配等级按更新时间倒序、资源类型和 ID 稳定排列。`limit` 在统一数据库查询中执行。

### 响应

```json
{
  "items": [
    {
      "id": "786da6f1-8c64-4150-af33-382ab105a519",
      "title": "Bug 排查助手",
      "resourceType": "PROMPT",
      "updatedAt": "2026-07-13T01:53:15.349Z",
      "matchField": "TAG",
      "matchText": "React"
    }
  ]
}
```

`resourceType` 可选值：

- `PROMPT`
- `SOLUTION`
- `NOTE`
- `MISCELLANY`
- `UI_PROTOTYPE`
- `MODEL_RESPONSE`，仅管理员会话可见

`matchField` 表示该结果的最高优先级命中字段，可选值为：

- `TITLE`
- `TAG`
- `SUMMARY`

`matchText` 为可选字段：标签命中时返回完整标签，摘要命中时返回围绕首次命中的截断摘要片段；标题命中时省略，避免重复传输标题。未认证请求的查询不会包含模型回答分支，因此不会返回或参与匹配模型回答的标题、摘要和标签。
