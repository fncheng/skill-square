# UI 原型库原型

## 原型文件

- [UI 原型库交互原型](../../../prototype/ui-prototype-gallery.html)

## 已体现的关键交互

1. 搜索和筛选原型卡片，并从列表打开预览。
2. 在桌面、平板和手机视口之间切换。
3. 展示新建原型入口、预览信息和外部资源策略。

## 实现边界

- 原型用于说明图库和预览交互，当前安全边界以 `UiPrototypeFrame`、`ui-prototype` 工具函数和 API 实现为准。
