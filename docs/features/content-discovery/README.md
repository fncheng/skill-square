# 内容发现

## 功能概览

内容发现通过全局搜索和标签词云帮助用户跨资源定位内容。

## 当前行为

- 顶部全局搜索统一检索 Prompt 的名称、描述和关联标签，以及解决方案、学习笔记、杂谈、UI 原型的标题、摘要和字符串标签；结果会显示标题、资源类型及标签或摘要命中上下文，并跳转到对应详情页。
- 有效管理员会话的顶部全局搜索额外检索并返回模型回答；访客查询从数据库查询结构上排除模型回答，模型回答不会参与匹配或排序。
- 标签词云聚合解决方案、学习笔记与杂谈的字符串标签，按忽略大小写的名称统计，同时保留原始名称展示。
- 标签词云支持按全部、解决方案、学习笔记或杂谈范围筛选，并按名称搜索标签。
- 点击标签进入分页内容列表，可继续按资源类型和关键词筛选；有效管理员会话的列表额外包含模型回答。
- 搜索和标签浏览均为读取能力，访客可以使用。

## 约束与限制

- 标签词云不聚合 Prompt 标签或 UI 原型标签。
- 标签词云仍只聚合解决方案、学习笔记与杂谈；标签内容列表对访客只返回这三类公开资源，对有效管理员会话额外返回模型回答，并按最近更新时间排列。
- 前端标签搜索只过滤已经从后端取得的词云数据；标签内容分页与关键词筛选由后端处理。
- 全局搜索采用不区分大小写的包含匹配，`%`、`_` 和 `\` 被视为普通字符；相关性依次为标题、标签、摘要，同一等级再按更新时间和稳定字段排序。首期不搜索正文、分类、Prompt 历史版本、模型名称或来源产品。
